# ต้นฉบับระบบเดิม (Google Apps Script)

วางไฟล์จากโปรเจค GAS เดิมไว้ในโฟลเดอร์นี้ เพื่อใช้เป็นต้นแบบตอนเขียนใหม่:

- `index.html` — หน้าแอปหลัก (login / home / ฟอร์ม EMS / ฟอร์ม REFER)
- `Code.gs` — backend ทั้งหมด (login, saveEMS, getEMSList, previewNextSeq, ...)
- `als.html`, `als_blank.html`, `refer.html`, `summary.html` — วิวสำหรับพิมพ์/รายงาน

สรุปสเปกที่ถอดออกมาแล้วอยู่ที่ `docs/legacy-app-spec.md`
