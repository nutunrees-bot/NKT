# สเปกระบบของจริง (ถอดจาก Google Apps Script เดิม)

ที่มา: ไฟล์ `index.html` ของเว็บแอป GAS ที่ ER รพร.นครไทย ใช้งานจริง (credit: Miss NutunreeS.)
สถาปัตยกรรมเดิม: Google Sheets = ฐานข้อมูล · Apps Script = backend · HTML เดี่ยว = frontend
ไฟล์นี้คือ **แหล่งความจริง** ของการเขียนใหม่ — ฟิลด์ทุกตัวต้องมาจากที่นี่ ไม่ใช่เดาเอง

---

## 0. โครงรวม

- **Login** → **Home** (2 การ์ด: EMS / REFER + รายการเคสให้ดู/แก้/ลบ) → ฟอร์ม EMS หรือ ฟอร์ม REFER
- ทุกอย่างเป็น **มือถือเป็นหลัก** (max-width 640px) — เจ้าหน้าที่กรอกหน้างาน
- มี draft autosave ลง localStorage (`nkt_ems_draft`) กันกรอกค้างแล้วหาย
- บันทึกเสร็จ → เด้ง modal ข้อความสรุปเคสให้ **คัดลอกส่ง LINE**

### หน้าจอ/วิวที่แยกไปอีกไฟล์ (ยังไม่มีต้นฉบับ — ต้องขอเพิ่ม)
| วิว | URL เดิม | คืออะไร |
|---|---|---|
| ALS | `?view=als&id=` | ฟอร์ม ALS สำหรับพิมพ์ของเคสนั้น |
| ALS เปล่า | `?view=als_blank` | ฟอร์ม ALS เปล่าไว้พิมพ์กรอกมือ |
| Refer | `?view=refer&id=` | ใบส่งต่อสำหรับพิมพ์ |
| สรุป | `?view=summary` | รายงานสรุป EMS & REFER |

### ฟังก์ชัน backend ที่ frontend เรียก (ต้องมีของใหม่ให้ครบ)
`login` · `logout` · `getServerTime` · `previewNextSeq(date)` ·
`saveEMS` · `updateEMS(id,data)` · `deleteEMS(id)` · `getEMSList(from,to)` ·
`saveRefer` · `updateRefer(id,data)` · `deleteRefer(id)` · `getReferList(from,to)`

- แถบบน: ชื่อเจ้าหน้าที่ · ปุ่ม "สรุป EMS&REFER" · ปุ่มออกจากระบบ

## 2. ฟอร์ม EMS

### 2.1 ข้อมูลทั่วไป
| ฟิลด์ | ชนิด | หมายเหตุ |
|---|---|---|
| วันที่ | date | บังคับ |
| ลำดับ (เหตุที่) | auto | ระบบออกให้เป็นลำดับที่ N ของวันนั้น · **ห้ามพิมพ์เอง** · แก้เคสเดิมไม่คำนวณใหม่ |
| เลขปฏิบัติการ | text | |
| เวร | เลือก 1 | เช้า / บ่าย / ดึก |
| เจ้าหน้าที่ผู้ให้บริการ 1 | dropdown | RN+AEMT (แสดง (RN)/(AEMT) ต่อท้าย) |
| เจ้าหน้าที่ผู้ให้บริการ 2 | dropdown | RN+AEMT |
| ผู้ช่วยเหลือ (PN/NA) | dropdown | รายชื่อผู้ช่วย |
| เจ้าหน้าที่ (พขร.) | dropdown | รายชื่อคนขับ |

ทุก dropdown มีตัวเลือก "อื่นๆ (พิมพ์เอง)"

**รายชื่อเจ้าหน้าที่ (hard-code อยู่ในโค้ดเดิม — ของใหม่ควรย้ายเป็นตารางใน DB)**
- RN (11): ยุทธพล, อรุณี, กนกวรรณ, นิชธาวัลย์, กลศาสตร์, เทอดพงษ์, วิภาลัย, จีระศักดิ์, กัญญา, นภเกตน์, สิริณัฐฐา
- AEMT (5): พัชรพร, จิตรานุช, ณัฎฐ์นรี, วรรณา, ณัฐริกา
- ผู้ช่วย PN/NA (7): กัลยา, ปริญาภรณ์, จินตนา, นภัทธัญธรณ์, นันท์นภัส, อานนท์, ชัยพร
- พขร. (7): สมศักดิ์, รณชิต, นิตินันท์, ฉัตรชัย, ไตรภพ, นุการ, ชยพล
- ผู้สรุปรายงาน = RN+AEMT · ชื่อผู้ประเมิน = **เฉพาะ RN**

### 2.2 เหตุการณ์
- รับแจ้งจาก: `1669` / `ER` / `วิทยุ`
- ประเภทเหตุการณ์: `พรบ` / `อุบัติเหตุ` / `ฉุกเฉิน`
- เหตุการณ์ (ข้อความยาว) · สถานที่ · เบอร์ผู้แจ้ง
- ระดับความรุนแรง: สีแดง / สีเหลือง / สีเขียว / สีขาว / **สีดำ**
- ประเภท: Trauma / Non-Trauma → สลับโชว์ section รายละเอียด
- พบเหตุ: `พบเหตุ` / `ไม่พบเหตุ` / `ไม่ประสงค์ รพ.`
  - เลือก **ไม่พบเหตุ → ล็อกทุก section ตั้งแต่ข้อมูลผู้ป่วยลงไป** (กรอกได้แค่ข้อมูลทั่วไป/เหตุการณ์/เวลา/เลขไมล์)

### 2.3 เวลาปฏิบัติการ (มีปุ่ม "ตอนนี้" ดึงเวลาจาก server)
รับแจ้ง · สั่งการ · ออกฐาน · ถึงเหตุ · ออกเหตุ · ถึง รพ. · ถึงฐาน

คำนวณสด:
- **Response time** = ถึงเหตุ − รับแจ้ง
- **Hospital Time** = ถึง รพ. − ออกเหตุ
- ติดลบ = ข้ามเที่ยงคืน ให้ +24 ชม.

### 2.4 เลขไมล์
ออก · ถึงเหตุ · ถึง รพ. · ถึงฐาน → **ระยะทางรวม = ถึงฐาน − ออก**

### 2.5 ข้อมูลผู้ป่วย
ชื่อ (พิมพ์คำนำหน้าด้วย) · อายุ · ID (เลขบัตร) · HN · Dx

- ที่อยู่ = dropdown ตำบล: นครไทย, หนองกระท้าว, นาบัว, เนินเพิ่ม, บ้านพร้าว, บ่อโพธิ์, ยางโกลน, ห้วยเฮี้ย, นครชุม, น้ำกุ่ม, นอกเขต
- สัญชาติ: คนไทย / แรงงานต่างด้าว / ชาวต่างชาติ (2 อันหลังโชว์ช่อง "ระบุ") — **กรอก ID แล้วติ๊ก "คนไทย" อัตโนมัติ**
- สิทธิการรักษา: บัตรทอง / ข้าราชการ / ประกันสังคม / แรงงานต่างด้าวขึ้นทะเบียน / ไม่มีหลักประกัน

### 2.6 Vital Signs
BP · PR · RR · BT · O2sat · GCS (E/V/M + รวมอัตโนมัติ) · Pupil ซ้าย/ขวา · DTX · Treatment

+ **ชุดประเมินซ้ำได้ไม่จำกัด** (เวลา + BP/PR/RR/BT/O2sat/GCS/Pupil/DTX) — ของเดิมยัดเป็น JSON ลงช่องเดียว

### 2.7 Trauma (โชว์เมื่อเลือก Trauma) — เลือกได้หลายค่า
- บาดแผล: No, Cut/Laceration, Abrasion, Contusion, Burn, Stab Wound, Amputate, GSW
- กระดูกผิดรูป: No, Closed, Opened, Dislocate
- การเสียเลือด: No, Ext/Stopped, Ext/Active, Int. Hemorrhage
- อวัยวะที่บาดเจ็บ: Head/neck, Face, Spine/back, Chest/Clavicle, Abdomen, Pelvis, Extremities, External body surface, Multiple injury

### 2.8 Non-Trauma (โชว์เมื่อเลือก Non-Trauma) — เลือกได้หลายค่า
- อายุรกรรม: Dyspnea, High Fever, Alteration of conscious, Seizure, Chest pain, Poisoning, Digestive, Other
- สูติ-นรีเวช: Labour pain/child birth, Bleeding per Vagina, High risk preg, Rape, Other
- กุมารเวชกรรม: Convulsion, High Fever, Dyspnea, Digestive, Other
- ศัลยกรรม: Ac. abdominal pain, GI Bleeding, Other
- อื่นๆ: Eye, ENT, Ortho, Psychological problem

> ตัวเลือกที่ขึ้นต้นว่า Other/Others → โชว์ช่องพิมพ์ระบุ เก็บเป็น `Other: <ข้อความ>`

### 2.9 การช่วยเหลือ (Treatment) — เลือกได้หลายค่า
- ทางเดินหายใจ: No, Clear airway, Suction, Oral airway, O2 canula/mask, Ambu bag, ET
- บาดแผล/ห้ามเลือด: No, Pressure Dressing, Dressing
- การให้สารน้ำ: No, NSS, RLS, 5%DN/2, On locked, Others
- ดามกระดูก: No, เฝือกลม/ไม้ดาม/Sling, Collar with Long Spinal Board, เฝือกหลังและคอ (KED)
- CPR: No, Yes, AED/Defib

**ผลการดูแลรักษาขั้นต้น** (เลือก 1): ไม่ยอมให้รักษา / ทุเลา / คงเดิม-คงที่ / ทรุดหนัก / เสียชีวิต ณ จุดเกิดเหตุ / เสียชีวิตขณะนำส่ง

- เลือก **"เสียชีวิต ณ จุดเกิดเหตุ"** → ต้องมี **ลายเซ็นญาติ (วาดบนจอ)** + ชื่อ-นามสกุลญาติ + **รูปถ่ายยืนยันหน้างาน** (ย่อ ≤900px, JPEG 70%)
- checkbox **รักษาประคับประคองตามอาการ (Palliative)** → ลายเซ็นญาติ + ชื่อญาติ อีกชุด

### 2.10 สรุปรายงาน
ผู้สรุปรายงาน (RN+AEMT) · ชื่อผู้ประเมิน (เฉพาะ RN)

### 2.11 ผลการรักษา
`D/C` / `Admit` / `Refer` / `Death` — เลือก Refer → โชว์ช่อง "ส่งต่อโรงพยาบาล" (ค่าเริ่มต้น รพ.นครไทย)

### 2.12 หลังบันทึก
เด้งกล่องข้อความสรุปเคส (เบอร์ผู้แจ้ง, ระดับ/ประเภท, เวลาทุกจุด, เลขไมล์, ผู้ป่วย, ID/HN, ที่อยู่, อาการ, Dx, V/S, GCS, Pupil, DTX, Treatment, ผลการรักษา, ส่งต่อ) → ปุ่ม **คัดลอกไปวางใน LINE**

## 3. ฟอร์ม REFER

| ฟิลด์ | ชนิด |
|---|---|
| วันที่ | date (บังคับ) |
| ชื่อผู้ป่วย · HN · อายุ · DX | text / number / textarea |

รพ. ปลายทาง: พุทธชินราช, ม.นเรศวร, ค่ายสมเด็จพระนเรศวรมหาราช, จิตเวชพิษณุโลก, ชาติตระการ, เนินมะปราง, บางกระทุ่ม, บางระกำ, พรหมพิราม, วังทอง, วัดโบสถ์

## 4. รายการเคส (หน้า Home)

- กรองด้วยช่วงวันที่ (จาก–ถึง) แยกกันระหว่าง EMS / REFER
- การ์ดแต่ละเคส EMS: ลำดับ, ชื่อผู้ป่วย, วันที่, ระดับ, ผลการรักษา, ผู้บันทึก + ปุ่ม **แก้ไข / พิมพ์ ALS / ลบ**
- การ์ด REFER: ชื่อ, วันที่, ระดับ, รพ.ปลายทาง, ผู้บันทึก + ปุ่ม **แก้ไข / ลบ / พิมพ์ Refer**
- ลบมี confirm "กู้คืนไม่ได้"
