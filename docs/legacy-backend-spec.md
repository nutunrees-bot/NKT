# สเปกหลังบ้านระบบเดิม (ถอดจาก `Code.gs`)

คู่กับ `docs/legacy-app-spec.md` (ภาคหน้าจอ) — ไฟล์นี้คือภาคข้อมูล + งานที่ทำอยู่เบื้องหลัง

## 1. ที่เก็บข้อมูล

Google Sheet เดียว แตกชีตรายเดือน:

| ชีต | เนื้อหา |
|---|---|
| `EMS_YYYY-MM` | เคส EMS ของเดือนนั้น (80 คอลัมน์) |
| `REFER_YYYY-MM` | เคสส่งต่อของเดือนนั้น (11 คอลัมน์) |
| `บันทึกเข้าระบบ` | log เข้า/ออกระบบ (เวลา, รหัส, การทำงาน) |
| `สรุป` | ตารางสรุปรายเดือน สร้างใหม่ทุกครั้งที่บันทึก |
| `แดชบอร์ด` | การ์ดตัวเลข + เคสล่าสุด 8 รายการ + กราฟแท่งรายวัน |

`id` ของแต่ละเคส = `"EMS_2026-09!5"` (ชื่อชีต + เลขแถว) — **เปราะมาก** ลบแถวหนึ่งแล้ว id ของแถวถัดๆ ไปเลื่อนหมด
แก้วันที่ข้ามเดือน = ลบแถวจากชีตเดิมแล้ว append ชีตใหม่

## 3. การเข้าระบบ (ของจริง)

```js
STAFF_CODES = ERNKT001 … ERNKT016      // 16 รหัส
login: รหัสต้องอยู่ในลิสต์ และ password ต้องเท่ากับ id
```

- **รหัสผ่าน = รหัสผู้ใช้** และหน้าเว็บพิมพ์ password ให้อัตโนมัติตามที่พิมพ์ ID
- ไม่ผูกรหัสกับชื่อคน — ใครถือรหัสไหนก็ได้ ชื่อคนมาจากดรอปดาวน์ในฟอร์มต่างหาก
- ทุกครั้งที่ login/logout เขียนแถวลงชีต `บันทึกเข้าระบบ`

## 4. เลขลำดับ "เหตุที่ N"

`computeNextSeq_` = **นับจำนวนแถวที่มีวันที่ตรงกัน แล้ว +1**
ตอนแก้ไขเคสเดิมใช้เลขเดิมที่ส่งมาจากฟอร์ม (ไม่คำนวณใหม่)

## 5. งานเบื้องหลังตอนบันทึก

1. `updateSummary_()` — ล้างชีต `สรุป` แล้วสร้างใหม่ทั้งหมด นับรายเดือน: จำนวนเคส, แยกสี 5 สี, Trauma/Non, ประเภทเหตุ 3 แบบ, พบเหตุ 3 แบบ, ผลการรักษา 4 แบบ, ระยะทางรวม, เคส REFER + ระดับความรุนแรง 4 ระดับ
2. `updateDashboard_()` — สร้างชีต `แดชบอร์ด` ใหม่: การ์ด 6 ใบ (EMS วันนี้ / เดือนนี้ / REFER เดือนนี้ / สีแดง / สีเหลือง / ระยะทางรวม) + ตารางเคสล่าสุด 8 รายการ + กราฟแท่งจำนวนเคสรายวัน
3. `sendLineBroadcast_()` — **broadcast เข้า LINE OA ทันทีที่บันทึกเคส EMS ใหม่** (LINE Messaging API, token เก็บใน Script Properties `LINE_CHANNEL_ACCESS_TOKEN`) ถ้าไม่มี token ก็ข้ามเงียบๆ
4. รูปถ่ายยืนยัน → อัปขึ้น Google Drive โฟลเดอร์ `NKT Rescue - รูปถ่ายยืนยันการเสียชีวิต ณ จุดเกิดเหตุ` ตั้งค่าแชร์ "ทุกคนที่มีลิงก์" แล้วเก็บ URL ลงชีต
5. ลายเซ็นญาติ → เก็บเป็น **base64 data URL ยัดลงเซลล์ตรงๆ**
6. `onEdit` trigger — แก้ชีตด้วยมือแล้วสรุป/แดชบอร์ดอัปเดตตาม

## 6. หน้าพิมพ์ ALS (`?view=als`) — A4 หน้าเดียว 6 ส่วน

ตรรกะที่ต้องยกมาให้ครบ:

- **"ไม่พบเหตุ"** → ปั๊มตราแดงทับกลางฟอร์ม
- ระยะทาง: ไป = ไมล์ถึงเหตุ − ไมล์ออก · ไป รพ. = ไมล์ถึง รพ. − ไมล์ถึงเหตุ
- **เดาเพศจากคำนำหน้าชื่อ** (นาย/เด็กชาย = ชาย · นาง/นางสาว/เด็กหญิง = หญิง)
- ติ๊ก "คนไทย" อัตโนมัติถ้ามีเลข ID แม้ไม่ได้เลือกสัญชาติ
- ต่อท้ายชื่อเจ้าหน้าที่ด้วย (RN)/(AEMT) ตามรายชื่อ
- ตาราง Vital Signs: แถวแรกจากเคส + แถวประเมินซ้ำ + **เติมแถวว่างให้ครบอย่างน้อย 2 แถว**
- **"เสียชีวิต ณ จุดเกิดเหตุ" บังคับ RC Code = ดำ** ทั้งข้อ 3 และข้อ 5 พร้อมข้อความ "NO Tube NO CPR, NR" (ทับค่าระดับความรุนแรงที่เลือกไว้)
- ข้อ 5 ติ๊กอัตโนมัติจากช่อง Treatment: ไม่เลือกอะไร/เลือกแค่ "No" → "ไม่จำเป็น" · เลือกอย่างอื่น → "ทำและเหมาะสม"
- ข้อ 6 map จากผลการรักษา: Admit→Admitted Yes · D/C→ทุเลา · Refer→รักษาต่อที่อื่น · Death→เสียชีวิตใน รพ.
- `?view=als_blank` = ฟอร์มเดียวกันแต่ข้อมูลว่าง ไว้พิมพ์กรอกมือ

## 7. หน้าพิมพ์ REFER (`?view=refer`)
A4 ตั้ง: ข้อมูลผู้ป่วย + Trauma/Non + ระดับความรุนแรง + รพ.ปลายทาง + ทีมนำส่ง + ช่องเซ็นผู้ส่งต่อ/ผู้รับส่งต่อ

## 8. หน้าสรุป (`?view=summary`) — เลือกเดือนได้ พิมพ์ได้

- การ์ด 4 ใบ: ออกเหตุทั้งหมด · พบเหตุ · ไม่พบเหตุ · REFER ทั้งหมด
- แท่ง Trauma/Non-Trauma แยก EMS กับ REFER
- **โดนัทระดับความรุนแรง 5 สี**
- **แผนผัง SVG อำเภอนครไทย** — ER อยู่กลาง แตกเส้นประไป 11 ตำบล วงกลมโตตามจำนวนเคส
- แท่งจำนวนเหตุรายตำบล + แท่ง REFER แยกตาม รพ.ปลายทาง

## 9. ปัญหาที่เจอในระบบเดิม (ของใหม่ต้องไม่ซ้ำ)

1. **ช่อง "อาการ" ไม่เคยถูกบันทึกเลย** — คอลัมน์ 33 มีอยู่ ฟอร์ม ALS กับข้อความ LINE ก็พิมพ์ค่านี้ แต่หน้าฟอร์มไม่มีช่องให้กรอก (`data.symptoms` เป็น undefined ตลอด) → ของใหม่ต้องเพิ่มช่องนี้
2. **แดชบอร์ดโชว์คอลัมน์ผิด** — ช่อง "ผู้บันทึก" ดึง `r[48]` ซึ่งคือ "ส่งต่อ รพ." (ที่ถูกคือ `r[49]`)
3. **เลข "เหตุที่" ซ้ำได้** — นับจำนวนแถวแล้ว +1 ถ้าลบเคสกลางวันทิ้ง เคสถัดไปจะได้เลขซ้ำกับที่มีอยู่
4. **id เคสอ้างเลขแถว** — ลบเคสแล้ว id ของเคสอื่นเลื่อน คนที่เปิดหน้าค้างไว้กด "แก้ไข" อาจไปทับเคสอื่น
5. **รหัสผ่าน = รหัสผู้ใช้** และเป็นรหัสกลาง 16 ตัวที่เดาได้ (`ERNKT001`…) ไม่รู้ว่าใครกรอกจริง
6. **ลายเซ็นเก็บ base64 ในเซลล์** — เซลล์ Sheets จำกัด 50,000 ตัวอักษร ลายเซ็นยาวๆ มีสิทธิ์ทำบันทึกล้มทั้งเคส
7. **รูปถ่ายยืนยันตั้งแชร์ "ทุกคนที่มีลิงก์"** — รูปหน้างานผู้เสียชีวิตเปิดสาธารณะ ใครได้ลิงก์ก็เปิดดูได้
8. สรุป/แดชบอร์ดสร้างใหม่ทั้งชีตทุกครั้งที่บันทึก — ยิ่งข้อมูลเยอะยิ่งช้า
